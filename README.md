# 智汇 ERP · 中小企业经营管理台

> 一个可直接演示的 ERP 管理后台作品集项目。面向一家 120 人规模的智能硬件贸易公司，把员工、客户、订单、库存与经营数据收进同一个工作台。
>
> 纯静态前端 · 零框架 · 零依赖 · 零 CDN · 无构建步骤

**交付状态**：可运行　|　**技术栈**：HTML / CSS / ES6+　|　**生产依赖**：0　|　**数据存储**：localStorage

---

## 1. 业务背景

**深圳智汇科技有限公司**是一家约 120 人的智能硬件贸易公司，主营 IoT 网关、边缘计算设备、传感器与配件的分销及系统集成服务。

公司日常经营中存在三个典型问题：

- **数据分散**：员工、客户、订单、库存与销售目标分别记录在表格和不同系统中，管理者很难在一个界面看清经营全貌。
- **履约与库存脱节**：大客户订单周期长、SKU 多，库存预警和订单履约经常依赖人工核对。
- **经营分析滞后**：月度销售额、部门目标完成率要靠人工汇总，缺少可复用的筛选与对比视图。

本项目模拟这套业务的管理后台，重点演示「从经营总览，到人员/客户/订单/库存维护，再到报表复盘」的完整操作链路。所有数据均为虚构的演示数据。

## 2. 项目结构

```text
erp-demo/
├─ index.html               # 单页应用入口、登录页、应用外壳、SVG 图标 sprite
├─ README.md
└─ assets/
   ├─ style.css             # 全部样式：设计令牌、登录页、后台布局、响应式、动效
   ├─ data.js               # 数据层：种子数据、localStorage 持久化、格式化工具
   ├─ chart.js              # 自研 Canvas 图表引擎：折线面积图 / 环形图 / 分组柱状图
   └─ app.js                # 应用层：路由、视图渲染、筛选分页、表单、弹窗、导出
```

### 分层职责

| 层级 | 文件 | 主要职责 |
| --- | --- | --- |
| 数据层 | `assets/data.js` | 首次写入演示数据、读取/保存数据库、日期金额格式化、订单明细构造 |
| 图表层 | `assets/chart.js` | Canvas 高清绘制、入场动画、悬停 tooltip、主题取色、响应式重绘 |
| 应用层 | `assets/app.js` | hash 路由、页面渲染、筛选/分页状态、事件委托、弹窗与表单、CSV/JSON 导出 |
| 视图层 | `index.html` | 登录页和应用外壳的静态结构、SVG symbol 图标库 |
| 样式层 | `assets/style.css` | 统一设计令牌、组件样式、浅色/深色主题、320–1440px 响应式 |

## 3. 功能清单

### 3.1 登录与全局框架

- 演示账号登录：`admin / 123456`，错误账号会给出内联错误提示。
- 登录后写入 `session` 到 localStorage，刷新保持登录；退出后清除会话。
- 左侧导航 + 顶栏 + 内容区。窄屏下导航自动收为**底部图标导航**，内容区不产生横向滚动。
- 顶部全局搜索（按钮 / `/` / `Ctrl+K`）：聚合功能入口、员工、客户、订单与商品，支持方向键选择、Enter 打开、Esc 关闭。
- 通知中心：根据低库存、待发货、待付款数据实时生成通知，可全部标为已读并跳转对应模块。
- 用户菜单：返回工作台、系统设置、退出登录。
- 顶部深浅主题切换；主题偏好持久化。

### 3.2 工作台 Dashboard

- 4 个实时 KPI 卡片：本月销售额、本月订单数、客户总数、库存预警数。
- 近 6 个月销售额趋势折线图（Canvas 自绘，含面积渐变、节点、最新值气泡、悬停提示）。
- 全部订单状态分布环形图（待付款 / 待发货 / 已完成 / 已取消，含中心总数与图例）。
- 待办事项：本地可勾选，进度条实时更新并持久化。
- 公司公告：置顶与分类、公告详情弹窗、全部公告归档。
- 经营简报一键导出 CSV。

### 3.3 员工管理

- 15 名员工的表格：工号、姓名/邮箱、部门、职位/电话、入职日期、状态。
- 关键词搜索（姓名、工号、职位等）+ 部门筛选 + 分页（每页 8 条）。
- 新增员工：自动生成 `ZH0xx` 工号，必填项校验。
- 编辑员工：回填表单、保存后即时更新。
- 删除确认：二次确认弹窗，显示员工姓名与工号。
- 员工名册 CSV 导出（导出当前筛选结果）。

### 3.4 客户管理

- 12 家客户的表格：公司名称、等级、行业/区域、联系人、电话、累计交易额、状态。
- 客户等级标签：A / B / C 三档视觉区分。
- 关键词搜索 + 等级筛选 + 结果计数。
- 新增客户：自动生成客户编号，维护等级、行业、联系人、地址等完整档案。
- 编辑 / 删除客户，删除带确认提示。
- 客户清单 CSV 导出。

### 3.5 订单管理

- 20 笔订单：订单号、客户、销售单元、金额、状态、日期。
- 状态 Tab：全部 / 待付款 / 待发货 / 已完成 / 已取消，带数量角标。
- 关键词搜索订单号或客户名。
- 点击订单行展开商品明细：SKU、规格、数量、单价、小计、服务项、收货信息、付款条件、履约进度。
- 彩色状态标签与履约进度节点。
- 订单清单 CSV 导出。

### 3.6 库存管理

- 12 个 SKU：编号、名称、分类、当前库存、安全库存、单价、库存货值、状态。
- **低于安全库存整行红色高亮**，默认将预警商品置顶。
- 库存搜索 + 品类筛选。
- 入库 / 出库弹窗：实时预览操作前后库存与安全线差额。
- 出库数量超过当前库存时行内校验拦截；成功后立即更新表格、预警数、导航角标、顶部通知和 KPI。
- 库存流水写入本地数据；库存清单 CSV 导出。

### 3.7 报表中心

- 按月份（近 6 个月）+ 销售单元筛选，联动刷新汇总数据与柱状图。
- 4 个汇总 KPI：本期销售额、目标完成率、有效订单、平均客单价。
- Canvas 分组柱状图：实际销售额 vs 月度目标，含图例、悬停提示。
- 部门经营汇总表：负责人、目标、实际、完成率、订单数、合计行。
- 自动生成经营洞察文案；经营报表 CSV 导出。

### 3.8 系统设置

- 公司信息表单：名称、信用代码、行业、规模、联系人、电话、邮箱、官网、地址、简介；保存到 localStorage 并同步侧边栏公司名。
- 主题设置：浅色 / 深色两套主题，即时预览，刷新后保留。
- 数据管理：查看各实体数量和数据占用；导出完整 JSON 备份；一键恢复 15 位员工、12 家客户、20 笔订单、12 个商品的初始数据（带二次确认）。

### 3.9 通用体验

- 深蓝企业后台视觉，卡片圆角阴影、表格斑马纹与 hover、按钮状态、过渡动效。
- 空状态、Toast 成功/警告/错误提示、弹窗遮罩、Esc 关闭、焦点回填。
- 自绘图表适配浅色/深色主题，窗口尺寸变化时自动重绘。
- 数据全部保存在本机浏览器，不连接真实后端。

## 4. 技术栈

- **标记**：语义化 HTML5、内联 SVG symbol 图标（无外部图标库）
- **样式**：原生 CSS3，自定义属性（CSS Variables）、Flex/Grid、媒体查询、backdrop-filter、CSS 动画
- **逻辑**：ES6+（严格模式、IIFE、事件委托、模块 IIFE、Promise 以外的同步数据流）
- **持久化**：localStorage（数据库 + 登录态 + 主题 + 通知已读状态）
- **可视化**：Canvas 2D 手写折线面积图、环形图、分组柱状图（DPR 适配 + tooltip + 动画）
- **工程**：无 npm 依赖、无构建步骤、无外部 CDN、无后端

### 外部网络访问

页面运行时不请求任何外部资源。UI 中的 `Created By Deerflow` 为指向 `https://deerflow.tech` 的品牌署名超链接，仅在点击时打开，不参与页面渲染。

## 5. 如何运行

### 方式 A：本地 HTTP 服务（推荐）

在 Windows PowerShell 中执行：

```powershell
cd "D:\新建文件夹\job\erp-demo"
python -m http.server 8901 --bind 127.0.0.1
```

浏览器访问：

```text
http://127.0.0.1:8901
```

已使用 Python 3.13 的 `http.server` 在 `127.0.0.1:8901` 验证 `index.html` 与全部静态资源均返回 `200`。

### 方式 B：直接双击

直接双击 `index.html` 即可在 Chrome / Edge 中打开。已实测在 `file://` 模式下：

- 页面样式与脚本正常加载；
- 登录、数据持久化、刷新保持登录均可用；
- 无 JavaScript 运行时错误。

> 某些浏览器对 `file://` 下 localStorage 的限制更严格；如果发现数据没有保留，改用方式 A 启动本地 HTTP 服务即可。

### 建议环境

- Chrome / Edge 120+（其他现代浏览器亦可）
- 屏幕宽度 320px 至 1440px+

## 10. 已知边界与可扩展方向

- **无真实后端**：登录校验和业务数据都在前端模拟，不能作为生产鉴权使用。
- **数据仅限本机浏览器**：清除浏览器站点数据或更换设备后，演示会回到初始种子数据。
- **订单 / 商品为演示数据**：金额、客户、商品名称均为虚构，不对应真实企业。
- **可继续扩展**：订单创建与审批流、角色权限、库存流水明细页、真实后端 API、分页服务端化、导出 Excel / PDF、ECharts 之外的可视化主题等。
